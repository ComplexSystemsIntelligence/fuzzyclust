Fuzzy c-means: memberships and the fuzziness exponent#

Fuzzy c-means (FCM) is the workhorse of fuzzy clustering. Instead of assigning every sample \(\mathbf{x}_k\) to exactly one cluster, it assigns a membership degree \(\mu_{ik}\in[0,1]\) to every cluster \(i\), with \(\sum_i \mu_{ik}=1\). The algorithm alternates two closed-form updates derived from the c-means functional \(J=\sum_i\sum_k \mu_{ik}^m D^2_{ik}\):

  • the prototypes are membership-weighted means, \(\mathbf{v}_i = \sum_k \mu_{ik}^m\mathbf{x}_k / \sum_k \mu_{ik}^m\);

  • the memberships follow from the distances, \(\mu_{ik} = 1/\sum_j (D_{ik}/D_{jk})^{2/(m-1)}\).

Besides the number of clusters, the only algorithmic hyperparameter is the fuzziness exponent \(m>1\). This example shows what the memberships look like and how \(m\) controls the softness of the partition.

Generate three well-separated spherical clusters. make_fuzzy_blobs is the Python counterpart of the MATLAB toolbox function nDexample.

import matplotlib.pyplot as plt
import numpy as np

from fuzzyclust import FCM
from fuzzyclust.datasets import make_fuzzy_blobs
from fuzzyclust.plotting import plot_clusters, plot_membership_contours

# [snippet:fit]
X, y_true = make_fuzzy_blobs(n_clusters=3, n_samples_per_cluster=100, random_state=0)

fcm = FCM(n_clusters=3, m=2.0, random_state=0).fit(X)
# [/snippet:fit]
print(f"converged in {fcm.n_iter_} iterations, J = {fcm.objective_:.2f}")
print("prototypes:\n", fcm.cluster_centers_.round(2))

The fitted model exposes the partition as membership_ (one row per sample, one column per cluster) and the hard labels as labels_. The contour map shows the level curves of the maximal membership \(\max_i\mu_{ik}\); for FCM they are circles, because the norm is Euclidean.

fig, axes = plt.subplots(1, 2, figsize=(11, 4.5))
plot_clusters(X, fcm.labels_, fcm.cluster_centers_, ax=axes[0])
axes[0].set_title("hard labels (argmax of memberships)")
plot_membership_contours(fcm, X, ax=axes[1])
axes[1].set_title(r"contours of $\max_i \mu_{ik}$")
plt.tight_layout()

Effect of the fuzziness exponent \(m\)#

As \(m\to 1\) the partition becomes crisp (k-means); for large \(m\) all memberships approach \(1/c\). In practice, \(m=2\) is the standard choice, and \(m\in[1.5, 2.5]\) is a reasonable range to explore.

ms = [1.2, 2.0, 4.0]
fig, axes = plt.subplots(1, 3, figsize=(15, 4.3), sharex=True, sharey=True)
for ax, m in zip(axes, ms, strict=False):
    model = FCM(n_clusters=3, m=m, random_state=0).fit(X)
    plot_membership_contours(model, X, ax=ax, labels=False)
    pc = np.mean(model.membership_ ** 2) * 3
    ax.set_title(f"m = {m}   (PC = {pc:.2f})")
plt.tight_layout()

The partition coefficient \(PC=\frac1N\sum_{ik}\mu_{ik}^2\), printed in the titles, measures this: it is 1 for a crisp partition and \(1/c\) for a completely fuzzy one. On well-separated data the prototypes barely move with \(m\); on overlapping clusters a large \(m\) pulls them toward the global mean.

Parameter study: a finer scan of \(m\)#

The three panels above show the extremes; a scan of the exponent on the same data quantifies the trend. The partition coefficient and the classification entropy \(CE=-\frac1N\sum_{ik}\mu_{ik}\log\mu_{ik}\) change monotonically with \(m\), from a crisp partition (\(PC=1\), \(CE=0\)) toward the uniform one (\(PC=1/c\), \(CE=\log c\)). The prototypes themselves hardly move (the mean displacement from the \(m=2\) solution is 0.09 for \(m=10\), against a cluster standard deviation of 0.67), but the number of iterations grows, because softer memberships make every update a smaller step.

# [snippet:m_scan]
from fuzzyclust.validity import validity_indices

m_values = np.array([1.1, 1.2, 1.5, 2.0, 2.5, 3.0, 4.0, 6.0, 10.0])
rows = []
for m in m_values:
    model = FCM(n_clusters=3, m=m, random_state=0).fit(X)
    v = validity_indices(X, model.membership_, model.cluster_centers_, m=m, indices=["PC", "CE"])
    d = np.linalg.norm(model.cluster_centers_[:, None] - fcm.cluster_centers_[None], axis=2)
    rows.append((v["PC"], v["CE"], d.min(axis=1).mean(), model.n_iter_))
rows = np.array(rows)
# [/snippet:m_scan]

Take-away#

Fuzzy c-means returns a membership matrix rather than a labeling, and the exponent \(m\) is the only parameter that decides how soft that matrix is. On well-separated clusters the prototypes are almost independent of \(m\); what changes is the information in the memberships: the transition zones between the clusters widen, PC falls and CE rises monotonically, and the iteration needs more steps. Values near 1 reproduce k-means, and values above 3 wash the partition out toward \(1/c\), so \(m=2\) is the usual compromise, to be revisited when the clusters overlap or when outliers are present (see the example on the fuzziness exponent).
