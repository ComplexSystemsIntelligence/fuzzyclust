Appendix A
API reference

This appendix lists every public class and function of fuzzyclust, sub-package by sub-package, with the first sentence of its docstring. The lists are generated from the __all__ attribute of each module by book/build_api_appendix.py, so they are complete by construction; the full signatures, parameters, and attributes are in the online documentation and in the docstrings (help(fuzzyclust.cluster.GK)). The shared constructor parameters, fitted attributes, and methods of all clustering estimators are described once in section 2.3. The notation of the docstrings is that of table 2.1.
