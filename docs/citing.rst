Citing
======

If you use ``fuzzyclust`` in academic work, please cite the toolbox (see
``CITATION.cff`` in the repository) together with the original publications of
the methods you use — every docstring and every chapter of the book lists
them. The MATLAB predecessor is

   B. Balaskó, J. Abonyi, B. Feil, *Fuzzy Clustering and Data Analysis
   Toolbox for Use with MATLAB*, University of Veszprém, 2005.
