Citing
======

If you use ``fuzzyclust`` in academic work, please cite the toolbox together
with the original publications of the methods you use — every docstring and
every chapter of the book lists them.

   J. Abonyi, *fuzzyclust: fuzzy clustering and data analysis toolbox for
   Python*, version 1.0, 2026. Zenodo,
   `doi:10.5281/zenodo.24543755 <https://doi.org/10.5281/zenodo.24543755>`__.

The DOI `10.5281/zenodo.24543754 <https://doi.org/10.5281/zenodo.24543754>`__
always resolves to the latest version. The book is

   J. Abonyi, *Fuzzy Clustering and Data Analysis in Python: The fuzzyclust
   toolbox*, version 1.0, University of Pannonia, 2026.
   `PDF <fuzzyclust-book.pdf>`__.

``CITATION.cff`` in the repository holds the same information in machine-readable
form. The MATLAB predecessor is

   B. Balaskó, J. Abonyi, B. Feil, *Fuzzy Clustering and Data Analysis
   Toolbox for Use with MATLAB*, University of Veszprém, 2005.
